## 1. Tong Quan

Tang `core/` la "nao" cua he thong — dieu phoi toan bo flow tu khi nhan event nen moi den khi ghi ket qua len Redis.

```
src/core/
+-- __init__.py
+-- strategy_engine.py     # Dieu phoi strategy: load config, filter df, goi calculate_signals
+-- signal_filter.py       # KNN Trend filter — loc tin hieu truoc khi publish
+-- keyspace_monitor.py    # Lang nghe Redis Keyspace event, trigger engine
+-- redis_publisher.py     # Ghi OG/signal hash + publish pub/sub channel
+-- cleanup_worker.py      # Background thread doc dep du lieu cu
```

**Nguyen tac thiet ke:**
- Moi file = 1 trach nhiem duy nhat (Single Responsibility)
- Khong file nao import truc tiep indicator hay strategy class → chi qua engine
- Tat ca giao tiep Redis qua `redis_connect.py` (helper functions)
- Error handling: log + continue, KHONG crash he thong

```

  |        |
```

## 4. keyspace_monitor.py

### 4.2 Cach dung

### 4.3 Redis Keyspace Notification

He thong subscribe pattern: `__keyspace@0__:candle:*`

Khi Module 2 (price collector) ghi 1 nen moi len Redis bang `HSET`:
```
HSET candle:CAPITALCOM:US30:10:2026-03-07 22:00:00 open 42500 high 42550 ...
```
Redis se phat event keyspace, monitor nhan duoc va trigger flow tren.

## 5. redis_publisher.py

### 5.1 Chuc nang

| Ham | Mode | Mo ta |
|---|---|---|
| `publish_strategy_result(client, result, target_key)` | Realtime | Ghi OG + signal cho NEN HIEN TAI |
| `publish_backfill(client, result, max_per_list)` | Backfill | Ghi TOAN BO DataFrame len Redis |

### 5.2 Cau truc Redis output

#### OG Hash (tat ca nen, ke ca khong co signal)
```
Key:    OG:{strategy}:{provider}:{symbol}:{tf}:{datetime}
Vi du:  OG:comboATR:CAPITALCOM:US30:10:2026-03-07 22:00:00

Fields: date_time, close_time, provider, symbol, timeframe, timestampMs,
        signal, signalString, strategy, candle_key, created_at,
        open, high, low, close, volume,
        SMA, MACD, MACD_Signal, MACD_Hist, ATR,
        entry, sl, tp, sl_distance, tp_distance
```

#### Signal Hash (chi nen co signal BUY/SELL)
```
Key:    signal:{strategy}:{provider}:{symbol}:{tf}:{datetime}
Vi du:  signal:comboATR:CAPITALCOM:US30:10:2026-03-07 22:00:00
Fields: (giong OG hash)
```

#### Pub/Sub Channel
```
Channel: signals_channel:{strategy}:{provider}:{symbol}:{tf}
Vi du:   signals_channel:comboATR:CAPITALCOM:US30:10

Payload (JSON):
{
    "key": "signal:comboATR:...:2026-03-07 22:00:00",
    "payload": { ... tat ca fields ... }
}
```

#### List Keys (cho dashboard query)
```
OG list:     OG:{strategy}:{provider}:{symbol}:{tf}          -> [datetime1, datetime2, ...]
Signal list: signal:{strategy}:{provider}:{symbol}:{tf}      -> [datetime1, datetime2, ...]
```

### 5.3 Realtime vs Backfill

| | Realtime (`publish_strategy_result`) | Backfill (`publish_backfill`) |
|---|---|---|
| **Goi boi** | `keyspace_monitor.py` | `back_fill_og.py` |
| **So nen** | 1 nen (nen hien tai) | Toan bo df (thuong 900-1000 nen) |
| **OG** | Ghi 1 hash | Ghi tat ca hash (pipeline) |
| **Signal** | Ghi 1 hash (neu co) | Ghi tat ca hash co signal |
| **Pub/Sub** | Publish ngay | Khong publish (backfill ko can realtime) |
| **List** | lpush 1 item | Xoa list cu, ghi moi, trim |
| **Kiem tra trung** | `EXISTS` truoc khi ghi | Ghi de (overwrite) |

## 6. cleanup_worker.py

### 6.1 Chuc nang

| Ham | Mo ta |
|---|---|
| `run_periodic_cleanup(stop_event, interval, max_items)` | Chay trong thread, goi cleanup moi `interval` giay |
| `cleanup_old_data(max_items)` | 1 lan cleanup: scan + trim + xoa orphaned |
| `_cleanup_single_list(client, list_key, max_items)` | Xu ly 1 list key cu the |

### 6.2 Cach dung trong main.py

```python
import threading
from src.core.cleanup_worker import run_periodic_cleanup

stop_event = threading.Event()
cleanup_thread = threading.Thread(
    target=run_periodic_cleanup,
    args=(stop_event,),
    daemon=True,
    name="CleanupThread",
)
cleanup_thread.start()

# ... chay monitor ...

# Khi dung:
stop_event.set()
cleanup_thread.join(timeout=5)
```

### 6.3 Quy trinh cleanup

1. **Scan** tat ca list key matching `OG:*` va `signal:*`
2. Voi moi list co > 1000 items:
   - `RPOP` cac item cu nhat
   - `DELETE` hash key tuong ung (`{list_key}:{datetime}`)
3. **Orphaned detection**: scan hash key matching `{list_key}:*`, compare voi list → xoa hash ko con trong list
4. Log ket qua

### 6.4 Config

| Tham so | Gia tri mac dinh | Mo ta |
|---|---|---|
| `MAX_ITEMS_PER_LIST` | 1000 | So luong item toi da giu lai |
| `CLEANUP_INTERVAL` | 300 (5 phut) | Thoi gian giua 2 lan cleanup |
| `SCAN_BATCH_SIZE` | 500 | So key scan moi lan |

## 7. signal_filter.py

### 7.1 Chuc nang

Bo loc tin hieu — ket hop KNN Trend voi strategy signal de tao final signal.
Nam giua `strategy_engine` va `redis_publisher` trong pipeline.

| Ham | Mo ta |
|---|---|
| `apply_knn_filter(result, knn_config)` | Ap dung KNN Trend filter len 1 StrategyResult |

### 7.2 Logic loc

| Strategy Signal | KNN Prediction | Final Signal |
|---|---|---|
| BUY (1) | > 0 (bullish) | BUY (1) |
| SELL (2) | < 0 (bearish) | SELL (2) |
| BUY (1) | <= 0 | HOLD (0) |
| SELL (2) | >= 0 | HOLD (0) |
| HOLD (0) | Any | HOLD (0) |

### 7.3 Cac cot them vao DataFrame

| Cot | Mo ta |
|---|---|
| `strategy_signal` | Signal goc tu strategy (truoc khi filter) |
| `KNN_MA` | Duong xu huong chinh KNN |
| `KNN_AVG` | Duong trung binh cham KNN |
| `KNN_PRED` | KNN prediction: +1 bullish, -1 bearish |
| `KNN_COLOR` | 1 Up, -1 Down, 0 Neutral |

### 7.4 Config trong strategy_list.json

```json
{
    "name": "comboATR",
    "knn_filter": {
        "enabled": true,
        "n_neighbors": 3,
        "smoothing_period": 50
    }
}
```

Neu khong co truong `knn_filter`, se dung default config.
Neu `"enabled": false`, filter se bi tat va signal goc duoc giu nguyen.

### 7.5 Phu thuoc

```
signal_filter.py
  +-- indicators/KNN_trend.py  (calculate_knn_trend)
  +-- strategy_engine.py       (StrategyResult dataclass)
```

## 4. Data Flow

### 4.1 Realtime Mode (main.py)

```
Module 2 ghi nen moi len Redis
    │  HSET candle:CAPITALCOM:US30:10:2026-03-09 00:00:00
    v
keyspace_monitor.py
    │  Subscribe __keyspace@0__:candle:*
    │  Parse key → provider, symbol, timeframe
    │  Doc bucket nen tu Redis (get_candle_bucket)
    │  Build DataFrame OHLCV
    v
strategy_engine.py
    │  Load strategy_list.json
    │  Filter df theo (symbol, timeframe) cua tung strategy
    │  Goi strategy.calculate_signals(df_filtered)
    v
signal_filter.py  ★ MOI
    │  Chay KNN Trend tren df_result
    │  So sanh strategy signal voi knn_prediction
    │  Chi giu signal khi ca hai cung chieu (BUY+bullish / SELL+bearish)
    │  Luu signal goc vao cot 'strategy_signal'
    v
redis_publisher.py
    │  Ghi OG hash   → OG:{strategy}:{provider}:{symbol}:{tf}:{dt}
    │  Ghi signal hash → signal:{strategy}:{provider}:{symbol}:{tf}:{dt}
    │  Publish channel → signals_channel:{strategy}:{provider}:{symbol}:{tf}
    │  Maintain list  → OG:{...} va signal:{...}
    v
Module 5 (OF_ctrader) lang nghe channel → dat lenh
```

### 4.2 Backfill Mode (back_fill_og.py)

```
SQL Server (dbo.providers → lay tat ca provider)
    │  query dbo.providers
    v
back_fill_og.py
    │  Doc strategy_list.json → lay (symbol, timeframe)
    │  Loop: provider × symbol × timeframe
    │  get_candles(symbol, tf, provider, limit=1000)
    v
strategy_engine.py → redis_publisher.publish_backfill()
    │  Ghi TOAN BO nen len Redis (pipeline)
    │  Trim list max 1000
    v
Redis DB0 co san du lieu lich su
```

## 6. Redis Key Convention (DB0)

```
Candle (input - do Module 2 ghi):
  candle:{provider}:{symbol}:{tf}:{datetime}     → Hash (OHLCV)

OG (output - tat ca nen):
  OG:{strategy}:{provider}:{symbol}:{tf}:{datetime}     → Hash (payload)
  OG:{strategy}:{provider}:{symbol}:{tf}                 → List [datetime, ...]

Signal (output - chi nen co signal):
  signal:{strategy}:{provider}:{symbol}:{tf}:{datetime}  → Hash (payload)
  signal:{strategy}:{provider}:{symbol}:{tf}              → List [datetime, ...]

Pub/Sub Channel:
  signals_channel:{strategy}:{provider}:{symbol}:{tf}    → JSON message
```

### 6.1 Cau Truc Hash Payload

**Fixed fields** (co dinh moi hash deu co):
```
date_time, close_time, provider, symbol, timeframe, timestampMs,
signal, signalString,
strategy_signal,      ← signal goc tu strategy (truoc KNN filter)
strategy, candle_key, created_at,
open, high, low, close, volume,
entry, sl, tp, sl_distance, tp_distance
```

**Dynamic indicator fields** (them tu moi strategy + KNN filter):
```
comboATR    : SMA, MACD, MACD_Signal, MACD_Hist, ATR, KNN_MA, KNN_AVG, KNN_PRED, KNN_COLOR
MACrossover : MA_Short, MA_Long, ATR, KNN_MA, KNN_AVG, KNN_PRED, KNN_COLOR
RSI         : RSI, ATR, KNN_MA, KNN_AVG, KNN_PRED, KNN_COLOR
```

> **Ghi chu**: `signal` = final signal sau KNN filter; `strategy_signal` = signal goc truoc filter.
> Khi signal bi filter (strategy co signal nhung KNN nguoc chieu): `signal=0`, `entry/sl/tp=nan`.

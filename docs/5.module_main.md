# Module Main.py — Entry Point

> **File**: `main.py`
> **Vi tri**: root project
> **Ngay cap nhat**: 2026-03-09

---

## 1. Vai Tro

`main.py` la entry point duy nhat cua he thong realtime.
Ket noi tat ca module thanh phan thanh 1 flow hoan chinh:

```
main.py
├── setup_logger()                          # Log ra file + console (UTC)
├── disable_quick_edit_mode()               # Tat Quick Edit tren Windows
├── StrategyEngine(config_path)             # Load strategy_list.json
├── cleanup_worker thread (daemon, 5 phut)  # Background doc dep du lieu cu
└── while True:
      monitor_keyspace_notifications(engine)
      ├── KeyboardInterrupt → dung sach
      ├── ConnectionError  → close + retry 5s
      └── Exception        → log + dung
```

---

## 3. Flow Chi Tiet

### 3.1 Khoi dong

1. `sys.path.insert(project_root)`
2. `disable_quick_edit_mode()` — Tat Quick Edit tren Windows console
3. `setup_logger()` — Tao file `system_strategy.log` + console output
4. `StrategyEngine(config_path)` — Load `config/strategy_list.json`
5. Start `cleanup_thread` — daemon thread, chay nen

### 3.2 Vong lap chinh

Monitor subscribe `__keyspace@0__:candle:*`, khi co event `hset`:
1. Doc bucket nen tu Redis
2. `engine.run(df)` tinh signal
3. `redis_publisher` ghi OG/signal len Redis

### 3.3 Xu ly loi

| Loi | Xu ly |
|---|---|
| `KeyboardInterrupt` (Ctrl+C) | Log + break → shutdown sach |
| `redis.ConnectionError` | Log + `close_redis_client()` + `sleep(5)` → retry |
| `Exception` khac | Log (exc_info) + break → shutdown |

### 3.4 Shutdown

- `stop_event.set()` → bao cleanup thread dung
- `cleanup_thread.join(timeout=5)`
- `close_redis_client()` → dong tat ca ket noi Redis

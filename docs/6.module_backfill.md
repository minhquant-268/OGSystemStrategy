# Module Backfill — back_fill_og.py

> **File**: `back_fill_og.py`
> **Vi tri**: root project
> **Ngay cap nhat**: 2026-03-09

---

## 1. Vai Tro

Chay 1 lan de ghi 1000 nen lich su len Redis cho moi (provider, symbol, timeframe).
Dung khi restart server hoac khi can co du lieu OG/signal cho dashboard.

---

## 2. Flow

```
back_fill_og.py
├── get_all_providers()           # Query dbo.providers tu SQL DB
├── get_backfill_targets()        # Doc strategy_list.json → (symbol, tf)
│
└── Loop: provider × symbol × timeframe
      ├── get_candles(sym, tf, prov, 1000)     # Query 1000 nen tu SQL DB
      ├── StrategyEngine.run(df)               # Tinh signal
      └── publish_backfill(client, result)     # Ghi toan bo len Redis
            ├── OG hash (tat ca nen)
            ├── Signal hash (chi BUY/SELL)
            ├── OG list + Signal list
            └── Trim list max 1000
```

---

## 3. Chay

```bash
# Mac dinh: tat ca providers, 1000 nen
python back_fill_og.py

# Chi 500 nen
python back_fill_og.py --limit 500

# Chi 1 provider cu the
python back_fill_og.py --provider CAPITALCOM

# Custom config
python back_fill_og.py --config path/to/strategy_list.json
```

---

## 4. Cac Ham Chinh

| Ham | Mo ta |
|---|---|
| `get_all_providers()` | Query `SELECT provider_code FROM dbo.providers` |
| `get_backfill_targets(config_path)` | Doc strategy_list.json, lay symbol/tf tu enabled strategies |
| `run_backfill(provider, limit, config_path)` | Ham chinh: loop provider × target, query DB, run engine, publish |
| `_convert_timeframe_for_db(tf)` | Convert "10"→"m10", "60"→"h1", "1440"→"d" |

---

## 5. Xu Ly Dac Biet

| Truong hop | Xu ly |
|---|---|
| `--provider all` (mac dinh) | Query tat ca provider tu DB |
| `--provider CAPITALCOM` | Chi chay 1 provider |
| `symbols="all"` trong config | **Bo qua** — backfill can biet cu the symbol de query DB |
| `timeframes="all"` trong config | **Bo qua** — tuong tu |
| Strategy disabled | **Bo qua** — chi lay tu enabled strategies |
| DB khong co du lieu | Log warning, bo qua, tiep tuc target tiep theo |
| Redis khong ket noi | Dung ngay |

---

## 6. So Sanh Realtime vs Backfill

| | Realtime (`main.py`) | Backfill (`back_fill_og.py`) |
|---|---|---|
| **Nguon du lieu** | Redis (candle bucket) | SQL DB (get_candles) |
| **So nen** | 1 nen moi | 1000 nen lich su |
| **Trigger** | Redis Keyspace event | Chay thu cong 1 lan |
| **Publisher** | `publish_strategy_result()` | `publish_backfill()` (pipeline) |
| **Pub/Sub** | Publish ngay | Khong publish |
| **Provider** | Tu candle key | Tu DB (all hoac chi dinh) |
